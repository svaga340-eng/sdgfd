# MobEcome — превращение админов в мобов (Paper 1.21.11, Java 21)

## Команды
- `/mobecome` — открыть меню мобов (все живые мобы, постранично)
- `/mobecome back` — вернуться в человеческий облик, инвентарь возвращается

Право: `mobecome.use` (по умолчанию только OP).

## Как собрать .jar
**Вариант 1 (локально):** установите JDK 21 и Maven, в папке проекта выполните `mvn package`.
Готовый файл: `target/MobEcome.jar` → в папку `plugins` сервера.

**Вариант 2 (без установки):** загрузите проект в репозиторий GitHub — Actions (`.github/workflows/build.yml`)
соберёт jar, скачайте его в разделе Artifacts.

## Что делает
- Инвентарь/броня/оффхенд сохраняются в `plugins/MobEcome/data/<uuid>.yml` и очищаются; возвращаются по `/mobecome back`
  (также при выходе, смерти, остановке сервера и после краша — при заходе).
- Ник скрыт (невидимость + скрытый неймтег + имя в табе заменено на имя моба).
- Переносятся: HP, броня, сопротивление отбрасыванию, скорость, размер хитбокса, полёт (летающие мобы),
  дыхание под водой (водные), огнестойкость (огненные).
- ЛКМ — атака (урон моба) / выстрел; ПКМ — особая способность (у Warden — звуковой луч).
- В слоте 0 лежит «палочка способностей» — без предмета в руке сервер не получает ПКМ по воздуху.
